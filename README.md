# AI Governance Control Plane (PM Portfolio Project)

This repository showcases a **Specification‑Driven Development (SDD)** workflow for AI‑native product management.

The project demonstrates how **Markdown specs + reusable PM skills** can be used with AI tools to consistently generate high‑quality JIRA stories.

## Why this project exists
Enterprise teams deploying GenAI struggle with:
- Inconsistent guardrails
- Policy intent getting lost in execution
- Manual, error‑prone story writing

This repo treats **PM judgment as an asset** — encoded, reusable, and scalable.

## Repository Structure
- `/epics` — Product‑level intent and outcomes
- `/modules` — Functional specifications
- `/skills` — Reusable PM standards used by AI

## Key PM Concepts Demonstrated
- AI Governance & Risk Thinking
- Spec‑Driven Development (SDD)
- PM Skills as Code
- AI‑assisted delivery workflows
